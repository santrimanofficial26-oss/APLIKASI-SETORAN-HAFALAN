# 📖 PENA-Q - Aplikasi Setoran Hafalan Tahsin & Tahfidz
**SMP Pesantren Nahdlatul Wathon**

Aplikasi pengelolaan setoran hafalan Al-Qur'an (Tahsin & Tahfidz) berbasis Google Apps Script dengan database Google Sheets dan frontend modern.

---

## 🚀 Fitur Utama
- **Multi Role Access**: Guru Pembina, Supervisor Pembina, Siswa, & Administrator Sekolah.
- **Isolasi Data Pembinaan**: Setiap Guru Pembina hanya melihat siswa binaannya (20–30 siswa).
- **Format Input Fleksibel**: Toggle mode **📄 Halaman** vs **🔢 Ayat** untuk Iqro & Al-Qur'an.
- **Log Catatan Pembimbing**: Catatan pembimbing tersimpan dan tampil langsung di dashboard siswa.
- **PWA & Vercel Mobile Ready**: Wrapper fullscreen responsive dengan SplashScreen modern.

---

## 🛠️ Deploy Ke Vercel (1-Klik)
1. Buka [Vercel Dashboard](https://vercel.com/new).
2. Pilih repositori GitHub: `santrimanofficial26-oss/APLIKASI-SETORAN-HAFALAN`.
3. Klik **Deploy** (Tanpa konfigurasi tambahan).
